# fpga review: start here

This project is for reviewing FPGA designs. Read these two files at the start of every session, before doing any work:

1. **`claude/rules.md`**: the numbered list of rules for running this project. Follow all of them. Add any new rule D gives as the next numbered item.
2. **`claude/current_state.md`**: the latest snapshot of the project: what's done, what's in progress, open issues and next steps. Update it as `rules.md` describes.
